Warlay - version portable
==========================

Este ZIP contiene la version portable de Warlay: no necesita instalador.

  warlay.exe   -> Cliente de escritorio de Warlay. Un solo programa hace
                  todo: la interfaz grafica y tambien detectar partidas
                  LAN y tunelizar el trafico del juego. No hay ningun
                  servicio ni proceso aparte que instalar o iniciar.

Como usarla
-----------
1. Extrae TODO el contenido de este ZIP a una carpeta de tu eleccion.
2. Ejecuta warlay.exe.
3. Windows pedira permiso de administrador al abrirlo -- acepta el aviso
   de Control de Cuentas de Usuario (UAC). Es necesario porque capturar
   trafico en la red local requiere privilegios elevados; Warlay no usa
   esos privilegios para nada mas. Windows seguira pidiendolo cada vez
   que abras la app.
4. Listo. Ya puedes registrar servidores, crear o unirte a salas, y jugar.

Diferencias con el instalador
------------------------------
- El instalador copia los archivos a Archivos de Programa, crea accesos
  directos y un desinstalador que detiene la app antes de borrarla.
- La version portable no modifica el sistema: solo usa la carpeta donde
  la extrajiste. Podes moverla, copiarla a un USB, o borrarla sin dejar
  rastro (salvo los datos de la aplicacion, descritos abajo).

Datos de la aplicacion
-----------------------
Tanto la version instalada como la portable guardan su configuracion y
sus logs en la misma ubicacion:
  %APPDATA%\com.warlay.lanlauncher\

Soporte
-------
Si algo no funciona, revisa la pestaña "Consola" dentro de la app -- ahi
se ve el registro en vivo de lo que esta haciendo Warlay.
